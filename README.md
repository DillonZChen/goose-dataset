# GOOSE Dataset

Dataset and training plans for [GOOSE](https://github.com/DillonZChen/goose).

- `ipc2023lt` benchmarks originate from [here](https://github.com/ipc2023-learning/benchmarks).
- `fdr-ipc2023lt` benchmarks contain FDR transformations of the easy problems in `ipc2023lt`
- `neurips24` benchmarks are associated with our [NeurIPS'24 paper](https://arxiv.org/abs/2410.24080) for learning numeric planning heuristics.
- `aaai24` benchmarks are associated with our [AAAI'24 paper](https://arxiv.org/abs/2312.11143) for learning domain-independent heuristics.

Many thanks and acknowledgements must go towards the PDDL authors and Jendrik Seipp's [scorpion](https://github.com/jendrikseipp/scorpion) planner for generating the optimal plans.
